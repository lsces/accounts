# accounts

A Bitweaver package: a lightweight single-entry ledger for a sole trader. It imports bank and
payment-service statements, categorises each line by rule, and reports a tax year's income and
expenses for a self-assessment return. A small replacement for a full accounting package where
double-entry, VAT and payroll are not needed.

**Status:** skeleton only — nothing is installed or built yet. See `MANUAL.md` for the intended shape.
